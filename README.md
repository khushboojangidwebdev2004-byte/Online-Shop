# Online Shop

Laravel-based Online Shopping Website with Admin Panel.

## Project Features

- Admin Dashboard
- Product Management
- Category Management
- Subcategory Management
- Order Management
- Customer Management
- Shopping Cart
- Wishlist
- Frontend Website

## Technology Stack

- PHP
- Laravel
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap

## Installation

1. Clone the repository.
2. Run `composer install`.
3. Copy `.env.example` to `.env`.
4. Configure your database credentials in `.env`.
5. Run `php artisan key:generate`.
6. Run `php artisan migrate`.
7. Start the project using `php artisan serve`.
